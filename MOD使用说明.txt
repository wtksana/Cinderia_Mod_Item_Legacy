================================================================================
                    Cinderia 道具扩展 Mod 使用说明
================================================================================

版本：1.1.0
作者：wtksana
更新日期：2026-05-29

================================================================================
                              一、安装步骤
================================================================================

1. 安装 BepInEx
   ----------------------------------------
   - 下载 BepInEx 5.x/6.x (Unity Mono 版本)
   - 解压到游戏根目录（与 Cinderia.exe 同级）
   - 运行一次游戏，BepInEx 会自动生成必要的文件夹
   - 关闭游戏

2. 安装 Mod
   ----------------------------------------
   - 下载 Cinderia_Mod_Item_Legacy.dll
   - 将 DLL 文件放入：
     游戏根目录/BepInEx/plugins/
   - 如果 plugins 文件夹不存在，请手动创建

3. 启动游戏
   ----------------------------------------
   - 正常启动游戏
   - 如果安装成功，可以在游戏中按 F9 打开配置界面
   - 日志文件位置：游戏根目录/BepInEx/LogOutput.log

================================================================================
                              二、Mod 功能
================================================================================

【1】复制器道具
   ----------------------------------------
   - 新增 4 个等级的复制器道具（绿/蓝/紫/橙）
   - 效果：清空房间时，有概率额外复制一份房间奖励
   - 概率：
     * 绿色复制器：20%
     * 蓝色复制器：40%
     * 紫色复制器：60%
     * 橙色复制器：80%
   - 额外效果：提供额外道具格（1-4 个，根据等级）

【2】自选开箱
   ----------------------------------------
   - 打开大宝箱或中海盗宝箱时，不再随机给道具
   - 弹出选择界面，从候选池中选择你想要的道具
   - 保留原版的品质随机逻辑（白/绿/蓝/紫/橙）
   - 只改变具体道具的选择方式

【3】藏宝图调整
   ----------------------------------------
   - 统一藏宝图 2/3/4 的掉落逻辑
   - 清空房间后都会掉落海盗宝箱
   - 藏宝图 4 可配置小/中/大宝箱的概率
   - 默认概率：小 20%，中 40%，大 40%

【4】上一局继承
   ----------------------------------------
   - 结算时自动记录本局所有道具
   - 下一局进入第一个房间时弹窗
   - 可以选择一个道具继承到新局
   - 帮助快速开局

【5】技能刷新次数
   ----------------------------------------
   - 在原版刷新次数基础上额外增加
   - 默认增加 0 次（需要手动配置）
   - 适用于主动技能和被动技能选择界面

================================================================================
                            三、游戏内快捷键
================================================================================

【F9】配置界面
   ----------------------------------------
   功能：
   - 实时修改所有 Mod 配置项
   - 复制器概率、自选开箱、继承、藏宝图、技能刷新等
   - 每个配置项都有中文名称、说明和生效时机提示
   - 点击"保存配置"按钮保存到配置文件

   界面说明：
   - 窗口尺寸：1000x700
   - 布局：配置名称 [输入框] [生效时机]
   - 字体清晰，易于阅读
   - 支持滚动查看所有配置

【F10】道具选择
   ----------------------------------------
   功能：
   - 按等级筛选所有道具（白/绿/蓝/紫/橙）
   - 点击道具卡片即可在角色旁掉落
   - 包含 Mod 新增的复制器道具
   - 方便测试和快速获取道具

   界面说明：
   - 左侧：道具列表（网格布局，每行 3 个）
   - 右侧：道具详情（名称、稀有度、描述）
   - 道具卡片显示图标和名称
   - 鼠标悬停高亮

================================================================================
                            四、配置文件说明
================================================================================

配置文件位置：
游戏根目录/BepInEx/config/Cinderia_Mod_Item_Legacy.cfg

主要配置项：
   ----------------------------------------

[Duplicator] 复制器
   启用 = true                    # 是否启用复制器功能
   绿概率 = 0.20                  # 绿色复制器复制概率（0-1）
   蓝概率 = 0.40                  # 蓝色复制器复制概率（0-1）
   紫概率 = 0.60                  # 紫色复制器复制概率（0-1）
   橙概率 = 0.80                  # 橙色复制器复制概率（0-1）

[ChestSelection] 自选开箱
   启用 = true                    # 是否启用自选开箱功能

[LegacyInheritance] 上一局继承
   启用 = true                    # 是否启用继承功能
   候选道具列表 =                 # 上一局的道具列表（自动记录）

[TreasureMap] 藏宝图
   藏宝图4_小宝箱概率 = 0.2       # 小海盗宝箱概率/权重
   藏宝图4_中宝箱概率 = 0.4       # 中海盗宝箱概率/权重
   藏宝图4_大宝箱概率 = 0.4       # 大海盗宝箱概率/权重

[SkillSelection] 技能选择
   额外刷新次数 = 0               # 额外增加的刷新次数

================================================================================
                            五、常见问题
================================================================================

Q1：Mod 没有生效怎么办？
   ----------------------------------------
   A：检查以下几点：
   1. 确认 BepInEx 已正确安装
   2. 确认 DLL 文件在 BepInEx/plugins/ 目录下
   3. 查看 BepInEx/LogOutput.log 是否有错误信息
   4. 确认游戏版本与 Mod 版本兼容

Q2：按 F9/F10 没有反应？
   ----------------------------------------
   A：
   1. 确认 Mod 已正确加载（查看日志）
   2. 尝试在游戏主界面或游戏中按键
   3. 检查是否有其他 Mod 冲突

Q3：复制器道具没有出现？
   ----------------------------------------
   A：
   1. 确认配置文件中 Duplicator.启用 = true
   2. 按 F10 打开道具选择界面，选择对应等级查看
   3. 查看日志中是否有"已注入复制器道具"的信息

Q4：自选开箱没有触发？
   ----------------------------------------
   A：
   1. 确认配置文件中 ChestSelection.启用 = true
   2. 只有大宝箱和中海盗宝箱会触发自选
   3. 小宝箱不会触发自选

Q5：如何修改配置？
   ----------------------------------------
   A：两种方式：
   1. 游戏中按 F9 打开配置界面，实时修改并保存
   2. 直接编辑配置文件（需要重启游戏生效）

Q6：配置的"生效时机"是什么意思？
   ----------------------------------------
   A：
   - "立即生效"：修改后立即生效，无需重启
   - "下一局生效"：需要开始新的一局才生效
   - "下一局生效"：需要重启游戏才生效

================================================================================
                            六、注意事项
================================================================================

1. 备份存档
   - 使用 Mod 前建议备份游戏存档
   - 存档位置通常在：C:\Users\用户名\AppData\LocalLow\游戏开发商\Cinderia

2. 游戏更新
   - 游戏更新后 Mod 可能失效
   - 请等待 Mod 更新或查看日志排查问题

3. Mod 冲突
   - 如果安装了多个 Mod，可能会有冲突
   - 建议逐个测试，确认哪个 Mod 有问题

4. 性能影响
   - 本 Mod 对性能影响很小
   - 如果遇到卡顿，可以尝试关闭部分功能
